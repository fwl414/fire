# 测试计划

## 1. 视觉模型配置测试

进入系统设置页，测试：

- VISION_ENABLED 是否读取为 true
- API Key 是否读取
- Base URL 是否为 https://open.bigmodel.cn/api/paas/v4
- 模型是否为 glm-4v-flash

## 2. 视觉接口测试

上传消防场景图片，期望返回：

- ok=true
- used_vision_api=true
- result 中包含隐患识别内容

## 3. 智能巡检测试

输入：

```text
实验室A区存在消防通道堵塞，插排串联，旁边堆放纸箱，配电箱周围也有杂物，电线较为杂乱。
```

期望：

- 识别出消防通道堵塞、插座过载、可燃物堆积、电线杂乱、配电箱周围堆物
- 风险等级为高风险或严重风险
- 自动生成巡检报告
- 自动生成故障工单

## 4. 错误处理测试

关闭后端或填错 API Key，前端不应只显示 Network Error，应显示后端返回的真实错误或降级提示。
