# 消防知识库扩展指南

## 1. 文档格式

每个知识文档建议使用 Markdown + Front Matter：

```markdown
---
title: 文档标题
category: 知识类别
keywords: 关键词1,关键词2,关键词3
source: 知识来源
---

# 文档标题

正文内容……
```

## 2. 推荐分类

- 疏散安全
- 电气安全
- 设施管理
- 可燃物管理
- 应急处置
- 场景管理
- 风险评估
- 整改处理
- 系统说明
- 常见问题

## 3. 编写原则

1. 一份文档聚焦一个主题；
2. 标题和关键词要覆盖常见问法；
3. 正文包含风险说明、常见隐患、处置建议；
4. 避免编造法规条文编号；
5. 如引用真实规范，应注明来源。

## 4. 示例

```markdown
---
title: 配电箱周边消防安全
category: 电气安全
keywords: 配电箱,配电柜,堆物,电气火灾
source: 系统内置消防知识库
---

# 配电箱周边消防安全

配电箱周边应保持清洁，不宜堆放纸箱、塑料等可燃物。
```
