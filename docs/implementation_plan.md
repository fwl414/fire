# 实施方案

## 1. 项目定位

项目名称：基于多模态Agent的智慧消防巡检与隐患处置系统。

项目以智慧消防巡检为业务场景，以Agent为核心技术，融合现场图片、巡检描述、设备档案、消防知识库和风险评分规则，实现消防隐患从发现、分析、评估到整改处理的管理。

## 2. 第一版目标

- 设备管理与一物一码概念展示
- 巡检任务创建与完成状态更新
- 智能巡检：图片 + 文本输入
- 智谱视觉模型接入与独立测试
- Agent 工具调用链展示
- 风险评分和整改建议
- 巡检报告生成
- 高风险自动生成故障工单
- 消防知识库问答
- Web 前端和 Flutter 移动端核心功能

## 3. 技术架构

- 前端：Vue3 + Element Plus
- 后端：FastAPI + SQLite
- 移动端：Flutter
- 视觉模型：智谱 AI GLM 视觉模型，OpenAI 兼容接口
- 知识库：本地 JSON 消防知识库
- 智能体：自定义 Agent 工具编排流程

## 4. Agent 流程

用户输入图片、巡检描述和设备信息后，系统按以下顺序执行：

1. 接收巡检输入
2. 调用文本隐患抽取工具
3. 调用真实视觉大模型或降级图片分析
4. 合并隐患标签
5. 调用风险评分工具
6. 检索消防知识库
7. 生成整改建议
8. 生成巡检报告
9. 高风险自动创建整改工单

## 5. 后续扩展

- 增加离线巡检同步
- 引入地图可视化
