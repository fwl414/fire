# Agent在智慧消防中的作用

Agent不是单纯聊天机器人，而是能够围绕消防巡检任务进行任务拆解、工具调用和结果综合的智能系统。

## Agent 任务流程

- 任务理解：理解巡检地点、设备、文字描述和图片输入。
- 工具选择：调用规则识别、文本智能模型、视觉智能模型、RAG 检索和风险引擎。
- 多源融合：融合规则、智能模型和视觉识别结果。
- 风险评估：根据隐患类别和严重程度计算风险评分。
- 应急决策：生成立即处置、短期整改和后续复查建议。
- 报告生成：形成可归档的巡检报告。

## 答辩说明

系统核心创新点在于智能体流程、工具调用记录、RAG 知识引用和风险可解释，而不是普通后台管理。
